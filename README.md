# Mini NPU 시뮬레이터 (Mini NPU Simulator)

AI 반도체(NPU)의 핵심 연산인 **MAC(Multiply-Accumulate, 곱누적)** 연산을 외부 수치 연산 라이브러리(NumPy 등) 없이 순수 파이썬으로 구현하고, 이를 통해 3x3 ~ 25x25 크기의 패턴이 **Cross(+)**인지 **X** 모양인지 판별하는 경량 시뮬레이터입니다.

---

## 1. 프로젝트 구조 및 파일 구성

유지보수성과 직관성을 위해 **연산 도구 엔진(`engine.py`)**과 **실행/입출력 인터페이스(`main.py`)**  2개의 파일로 간결하게 구성되어 있습니다.

main.py (진입점 / 모드 1 / 모드 2 / 파일 I/O)
     │
     ▼ (도구 호출)
  engine.py (행렬 생성 / MAC 연산 / 라벨 정규화 / 판정 / 성능 측정)
